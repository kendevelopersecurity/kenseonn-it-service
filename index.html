04 / FAQ

Ketentuan

Apakah layanan security testing legal?

Ya, hanya untuk aset milik klien atau aset yang memiliki izin pengujian. Scope, target, waktu, dan batas pengujian harus disepakati sebelum pekerjaan dimulai.

Apakah data pelanggan aman?

Order disimpan di Firebase Firestore. Akses order dibatasi untuk admin, sementara pengunjung hanya dapat membuat order baru. Tetap hindari memasukkan password, OTP, private key, atau data sensitif ke formulir.

Bagaimana cara order?

Pilih layanan, isi detail kontak dan kebutuhan, lalu kirim. Admin akan menghubungi Anda untuk konfirmasi scope, harga, jadwal, dan ketentuan.

05 / ORDER

Request Service

Isi detail layanan dan tautan publik yang relevan. Admin akan memeriksa pesanan secara manual. Jangan masukkan password, OTP, token, atau kredensial akun.
