KENSEONN PREMIUM UPGRADE

Perubahan utama:
- Loading overlay nyata untuk pemilihan layanan dan pengiriman order; spinner tombol pada proses admin.
- Paket boosting dikelompokkan per jenis layanan dan deskripsi paket dapat diatur dari admin.
- Ulasan pelanggan dikelola melalui tab Ulasan & Like di admin. Tidak ada ulasan demo/fiktif yang dibuat otomatis.
- Like ulasan disimpan ke Firestore dengan satu dokumen per UID pelanggan yang login; angka berasal dari dokumen like yang terbaca.
- Design Lab diberi tampilan studio yang lebih rapi dan preview lebih jelas.
- File versi utama dan nested V2.1 disinkronkan.

PENTING SETELAH DEPLOY:
1. Deploy firestore.rules yang sudah ditambahkan. Perubahan rules ini bersifat aditif: semua rules lama tetap dipertahankan.
2. Aktifkan Firebase Authentication Email/Password dan pastikan pelanggan login untuk memberi like.
3. Admin perlu memasukkan feedback pelanggan asli di tab Ulasan & Like. Tidak ada ulasan atau rating palsu.
4. Boosting real/otomatis belum terhubung ke provider API. Untuk auto-delivery diperlukan API resmi penyedia layanan, dokumentasi endpoint, dan kredensial rahasia di backend/Cloud Functions. Jangan letakkan API key provider di app.js.
5. Pembayaran masih manual; tidak ada gateway atau verifikasi otomatis.

ENTERPRISE SUITE V22 (20 MODULES)
- Added Enterprise Suite workspace to admin.html/admin.js/admin-premium.css.
- 20 modules have admin-side record create/read/update/delete backed by Firestore enterpriseRecords.
- New Firestore rule: enterpriseRecords read/write restricted to enabled admins.
- Modules cover P&L, ledger, pricing, forecast, abandoned orders, live-chat records, loyalty, referrals, disputes, segmentation, provider registry/health/failover policy, tracking, refunds/refills, role matrix records, 2FA policy records, fraud cases, recovery logs, and performance incidents.
- External payment/API/chat/push/2FA automation is not activated by storing a record; it requires verified credentials and server-side integration. Secrets must never be stored in Firestore client-readable documents.
